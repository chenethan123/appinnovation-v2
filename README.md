# FormulaQuizzer - AI-Powered Study App

An educational quiz application with **unlimited subjects**, **AI-generated questions** powered by ChatGPT, and **adaptive learning algorithms**.

## 🚀 Quick Start

### For Development (Local Testing)

```bash
./start_app.sh
```

This automatically starts:
- ✅ Node.js backend server (ChatGPT integration)
- ✅ Flutter macOS app
- ✅ Complete integration ready to use!

### For Production (Published App)

**Even simpler - Direct OpenAI Integration!** 🎉

1. Get OpenAI API key from: https://platform.openai.com/api-keys
2. Update `lib/config/api_config.dart` with your key
3. Run: `flutter run -d macos`
4. Click "AI Quiz (ChatGPT)" - works immediately!

📖 **See**: [SETUP_API_KEY.md](./SETUP_API_KEY.md) for step-by-step guide

**Alternative**: Deploy backend to cloud (Railway/Render)
📖 **See**: [PRODUCTION_DEPLOYMENT.md](./PRODUCTION_DEPLOYMENT.md)

## 🎯 How It Works

### Timer Flow
```
Start Timer (5-15 min) → Pick Random Subject → Call Backend
     ↓
Backend: Check Cache → Generate with ChatGPT → Return MCQ
     ↓
Flutter: Display Question → User Answers → Show Explanation
     ↓
Save to SQLite → Update Stats → Schedule Next Quiz
```

### MCQ Schema
Every question includes:
- **stem**: Question text
- **options**: 2-5 choices with letters (A, B, C, D, E)
- **correct_option**: The right answer
- **explanation_correct**: Shown when user is correct
- **explanations_by_option**: Why EACH option is right/wrong
- **difficulty**: easy/medium/hard
- **source_hint**: Topic tag
