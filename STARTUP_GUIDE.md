# FormulaQuizzer - Complete Startup Guide

## 🚀 One-Command Startup

The app is now configured to start both the backend and Flutter app with a single command!

### Quick Start (Recommended)

```bash
cd "/Users/ethanchen/Desktop/CS Stuff/formula_quizzer"
./start_app.sh
```

This script will:
1. ✅ Check if Node.js is installed
2. ✅ Install backend dependencies if needed
3. ✅ Start the Node.js backend server (port 8787)
4. ✅ Launch the Flutter app on macOS

The `.env` file is already configured with your OpenAI API key. To check:


You should see `OPENAI_API_KEY=sk-proj-...`

## 🎯 How It Works

### Backend Server (Node.js + Express)
- **Location**: `/server` directory
- **Port**: 8787
- **Endpoints**:
  - `POST /api/generate-mcq` - Generate single MCQ
  - `POST /api/generate-mcq-batch` - Generate multiple MCQs
  - `GET /api/health` - Health check

### Flutter App
- Connects to backend at `http://localhost:8787`
- Uses `AIService` to communicate with backend
- Displays MCQs with option-specific explanations

## 🔄 Usage Flow

### 1. Timer-Based Quizzes (Automated)

On the **Home** screen:
1. Find the "Timer Quiz" card
2. Set min/max interval (e.g., 5-15 minutes)
3. Click **"Start Timer"**
4. App will automatically:
   - Pick a random subject from your active subjects
   - Call backend to generate MCQ with ChatGPT
   - Show notification when quiz is ready
   - Repeat at random intervals

### 2. Manual Quizzes (On-Demand)

On the **Home** screen:
1. Click **"Generate Question"** in Timer Quiz card
2. Or use **"Random Quiz"** in Quick Quiz section
3. Quiz screen opens with AI-generated MCQ
4. Select your answer
5. Click **"Submit Answer"**
6. See explanation:
   - ✅ **Correct**: Shows `explanation_correct`
   - ❌ **Wrong**: Shows option-specific explanation for your choice

### 3. View Explanations

After answering:
- **Correct answer**: Green card with encouraging message + explanation
- **Wrong answer**: Orange card with why your choice was wrong
- **All options**: Each has a pre-generated explanation from ChatGPT

## 🐛 Troubleshooting

### "command not found: npm"
**Solution**: Install Node.js (see Step 1 above)

### Backend fails to start
**Check**:
```bash
cd server
npm run dev
```

Look for errors in output. Common issues:
- Missing `.env` file → Copy from `.env.example`
- Invalid API key → Check `.env` has correct key
- Port 8787 in use → Change PORT in `.env`

### "Failed to generate question"
**Causes**:
1. Backend not running → Start with `./start_app.sh`
2. No internet connection → Check network
3. OpenAI API error → Verify API key and credits
4. No active subjects → Add subjects first

**Debug**:
```bash
# Check backend logs
tail -f server/backend.log

# Test health endpoint
curl http://localhost:8787/api/health
```

### Flutter build errors
```bash
flutter clean
flutter pub get
flutter run -d macos
```

- ~$0.02-0.04 per MCQ
- Batch generation uses same cost
- Cache reduces API calls by ~70%

**Monitor Usage**:
- Dashboard: https://platform.openai.com/usage
- Set billing alerts on OpenAI account
- Review cache stats: `curl http://localhost:8787/api/cache/stats`

**Tips to Save Money**:

2. Batch generate for common subjects

## 📚 Architecture

```
formula_quizzer/
├── lib/
│   ├── models/
│   │   └── mcq.dart              ← MCQ data model
│   ├── providers/
│   │   └── mcq_provider.dart     ← State management + timer
│   ├── screens/
│   │   ├── home_screen.dart      ← Main UI
│   │   └── mcq_quiz_screen.dart  ← Quiz interface
│   ├── services/
│   │   └── ai_service.dart       ← Backend API client
│   └── widgets/
│       └── timer_quiz_card.dart  ← Timer controls
├── server/
│   ├── src/
│   │   ├── index.ts              ← Express API
│   │   ├── openai.ts             ← ChatGPT integration
│   │   └── cache.ts              ← LRU cache
│   └── .env                      ← API key config
└── start_app.sh                  ← Startup script
```

### Data Flow

```
Timer fires → Pick random subject → AIService.generateMCQ()
     ↓
http://localhost:8787/api/generate-mcq
     ↓
Backend checks cache → If miss, call OpenAI
     ↓
GPT-4 Turbo generates MCQ with ALL explanations
     ↓
Backend validates + caches → Returns MCQ
     ↓
Flutter displays question + options
     ↓
User answers → Show appropriate explanation
     ↓
Save result to SQLite → Update stats
```

## 🔧 Configuration

### Timer Settings
- **Location**: Home screen → Timer Quiz card
- **Min interval**: 1-30 minutes
- **Max interval**: 2-60 minutes

### Backend Settings
Edit `server/.env`:
```bash
PORT=8787                    # API port
CORS_ORIGIN=*                # Allow all origins
CACHE_TTL_MINUTES=5          # Cache expiry
CACHE_MAX_SIZE=50            # Max subjects cached
```

### Flutter Settings
Edit `lib/services/ai_service.dart`:
```dart
static const String _baseUrl = 'http://localhost:8787';
static const Duration _timeout = Duration(seconds: 30);
```
